# Tutorial screenshot checklist

The main README expects the screenshots below. Add PNG files using these exact names and they will appear automatically in the guide.

## `01-configuration.png`

Show the RuneLite configuration panel with the default potion counts, station order, and Display section visible. A narrow crop is fine as long as the plugin name is readable.

## `02-mixing-guidance.png`

Show an active mixing step with:

- the permanent Mox, Aga, and Lye letters;
- the bright current-recipe numbers;
- gray next-recipe numbers;
- `4` on the mixing vessel;
- the instruction panel and potion queue.

## `03-processing-guidance.png`

Show a full or partial inventory with `#1`, `#2`, and `#3` markers, the current inventory slot outline, and the correct processing station highlighted.

## `04-menu-guard.png`

Open the right-click menu on a station that is not currently available. Capture the existing **Check** entry in the default position and the original processing action elsewhere in the same menu. There should be only one **Check** entry.

## Capture safety

- Hide or crop chat, account names, friends lists, and login information.
- Avoid showing world or session details that you do not want published.
- Prefer a clean RuneLite layout at a readable UI scale.
- Crop empty space, but retain enough of the laboratory to make each highlighted object recognizable.
- Keep each image reasonably compressed so the Plugin Hub page loads quickly.
